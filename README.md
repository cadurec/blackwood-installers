# Blackwood — instaladores

Instaladores dos plugins Blackwood para o Final Cut Pro. **Só binários, sem código-fonte.**
Os plugins só funcionam com uma conta ativa no app **Blackwood Suite**, que baixa e instala tudo daqui.

- `manifest.json`: versão atual de cada plugin e o link do instalador (lido pelo backend do Suite).
- Cada instalador fica num Release com a tag `<plugin>-v<versao>`.
